# Security Policy

## Supported Versions

This project does not maintain multiple released versions. Security fixes are
applied to the `main` branch only.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather
than opening a public issue or pull request.

- Email: eng.omarnizam@gmail.com
- Include a description of the issue, steps to reproduce, and its potential
  impact.

You should expect an initial response within a few days. Once a fix is
available, it will be released on `main` and the reporter credited unless
they prefer to remain anonymous.
